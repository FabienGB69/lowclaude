Organize complex information using the Memory Palace (method of loci) technique.

When invoked with $ARGUMENTS (a concept, codebase area, or topic to memorize/organize):

1. **Build the palace** — Choose a familiar spatial metaphor (a building, a city, a journey) that maps naturally to the structure of the information.
2. **Place the items** — Assign each key concept, function, or data point to a specific "room" or location. Make the associations vivid and weird — unusual things stick.
3. **Create the walkthrough** — Write a narrative description of walking through the palace, encountering each concept in sequence.
4. **Draw the map** — Output a visual ASCII or markdown map of the palace with labels.
5. **Quiz mode** (if requested) — Ask questions that require "walking" through the palace to retrieve answers.

Use this for: understanding a new codebase, memorizing an API, onboarding to a complex system, or explaining architecture to others.
