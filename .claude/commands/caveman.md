Strip everything back to first principles. No jargon, no frameworks, no assumptions.

When invoked with $ARGUMENTS (a concept, problem, or piece of code):

1. **What is this, really?** — Explain it like the user has never heard of it. No buzzwords.
2. **Why does it exist?** — What basic human/technical need does it solve?
3. **What's the simplest possible version?** — Reduce to the minimal working idea (10 lines of code, one sentence, a stone-age analogy).
4. **What complexity was added and why?** — Trace each layer of complexity back to a real requirement.
5. **What can we remove?** — Identify anything that exists for historical reasons, cargo-cult thinking, or over-engineering.

Goal: after this skill runs, the core idea should feel obvious and simple.
